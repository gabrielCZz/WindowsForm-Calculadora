## 📌 Descrição
Este projeto consiste em uma **calculadora simples (semi-científica)** desenvolvida em **C# com Windows Forms no Visual Studio 2022**.  
O objetivo é fornecer uma interface intuitiva para realizar operações matemáticas básicas e algumas funções adicionais, respeitando o separador decimal conforme a cultura do sistema.

---

## ⚙️ Funcionalidades
- Operações aritméticas básicas:  
  ➕ Soma  
  ➖ Subtração  
  ✖️ Multiplicação  
  ➗ Divisão  

- Operações adicionais:  
  √ Raiz quadrada  
  𝑥ʸ Potência (elevação de um valor por outro)  
  🔄 Limpar tela (C)
